# CyberTank 联机模式（1v1）部署指南

> 目标：给原本的纯前端单机小游戏加上**完整联机 1v1**，支持「创建房间 / 输入房间号加入 / 无房间号时公网自动匹配」。
> 技术栈：**Node.js + Socket.IO**（免费、轻量，无付费 SDK）。服务端跑权威模拟，前端只负责渲染与采集输入。

---

## 1. 整体架构说明

```
┌─────────────┐         Socket.IO (WebSocket)        ┌──────────────────────────┐
│  前端客户端  │  ── input(移动/瞄准/开火/技能) ──▶   │       Node 服务端         │
│ (浏览器/游戏)│  ◀── snapshot(位置/血量/子弹) ───    │  权威模拟 + 房间/匹配管理  │
└─────────────┘                                     └──────────────────────────┘
```

**关键原则（降低作弊）**：客户端**永远不能直接改状态**。它只上报「我想往哪走、瞄哪、开火没」，所有物理、命中、扣血、冷却都在服务端按固定步长算完后，把「快照」广播给双方。两端画的是同一份数据，天然一致、无法作弊。

### 两种进入模式

| 模式 | 流程 | 适用 |
|------|------|------|
| **房间模式** | `createRoom` → 拿到 6 位房间号 → 好友 `joinRoom(房间号)` 加入 | 和好友约战、局域网 |
| **公开匹配** | `quickMatch` → 进入等待队列 → 服务端凑满 2 人自动成房 | 公网随时来一局，无需约号 |

两种模式在服务端最终都收敛为一个 `Room`，后续模拟逻辑完全一致，区别只在「怎么凑齐两个人」。

### 同步模型

- 服务端 `TICK_HZ = 30`：每秒模拟 30 步，每步后广播一帧快照。
- 客户端：渲染循环（requestAnimationFrame）只画最近一帧快照；输入按 30Hz 上报。
- 本方案**不做客户端预测**（最简单、最稳、零不同步）。进阶可选：对本地坦克做「输入预测 + 服务端校正」，手感更跟手（见第 6 节）。

## 3. 完整服务端代码 `server.js`

> 已随本指南放在 `online/server.js`，下面为完整内容（含房间管理、匹配队列、数据同步校验）。

```js
/**
 * server.js —— CyberTank 1v1 联机服务端（权威模拟）
 * 技术栈：Node.js + Express（静态托管）+ Socket.IO（实时通信）
 * 设计要点：服务端持有权威状态；客户端只报输入；固定步长模拟+快照广播；房间+公开匹配。
 */
'use strict';
const path = require('path');
const http = require('http');
const express = require('express');
const { Server } = require('socket.io');

// ---------- 0. 基础配置 ----------
const PORT = process.env.PORT || 3000;
const TICK_HZ = 30;
const TICK_DT = 1 / TICK_HZ;

// 竞技场与规则（全部服务端定义，客户端不可篡改）
const ARENA = { w: 880, h: 600 };
const TANK_R = 18;
const TANK_SPEED = 175;
const BULLET_SPEED = 480;
const BULLET_R = 5;
const FIRE_CD = 0.32;        // 开火冷却：服务端限频核心
const DAMAGE = 12;
const MAX_HP = 100;
const SHIELD_MAX = 50;
const SKILL_CD = 6;
const SKILL_DUR = 2;
const ROUNDS_TO_WIN = 3;     // BO5
const COUNTDOWN = 3;
const ROUND_END_DELAY = 2.0;

// ---------- 1. 工具 ----------
function clamp(v, min, max) { return v < min ? min : (v > max ? max : v); }
function normAngle(a) { a = a % (Math.PI * 2); if (a < 0) a += Math.PI * 2; return a; }

const EMPTY_INPUT = { up:false, down:false, left:false, right:false, fire:false, skill:false, aim:0 };
// 清洗：把任意客户端数据变成安全布尔/数值，非法数据被丢弃或修正
function sanitizeInput(raw) {
  raw = raw || {};
  return {
    up: !!raw.up, down: !!raw.down, left: !!raw.left, right: !!raw.right,
    fire: !!raw.fire, skill: !!raw.skill,
    aim: normAngle(Number(raw.aim) || 0),
  };
}

// ---------- 2. HTTP + Socket.IO ----------
const app = express();
const server = http.createServer(app);
const io = new Server(server, { cors: { origin: '*' } }); // 开发期放开；公网改具体域名
app.use(express.static(path.join(__dirname, 'public')));
app.get('/health', (_req, res) => res.json({ ok: true, rooms: rooms.size, queue: matchQueue.length }));

// ---------- 3. 房间与队列 ----------
const rooms = new Map();      // 房间号 -> Room
const matchQueue = [];        // 公开匹配等待队列（socket.id）

function genRoomId() {
  const chars = 'ABCDEFGHJKLMNPQRSTUVWXYZ23456789'; // 去掉易混字符
  let id;
  do { id = ''; for (let i=0;i<6;i++) id += chars[Math.floor(Math.random()*chars.length)]; }
  while (rooms.has(id));
  return id;
}
function newTankState() {
  return { x:0,y:0, angle:0, turretAngle:0, hp:MAX_HP, shield:0, shieldTimer:0,
           fireCd:0, skillCd:0, alive:true, hitFlash:0 };
}
function createRoom() {
  const id = genRoomId();
  const room = {
    id, players:[null,null], state:'waiting', scores:[0,0], tick:0,
    countdown:0, roundEndTimer:0, lastWinner:-1,
    tanks:[newTankState(), newTankState()], bullets:[],
  };
  rooms.set(id, room);
  return room;
}
function placeTanks(room) {
  const [a,b] = room.tanks;
  a.x=ARENA.w*0.18; a.y=ARENA.h*0.5; a.angle=0;       a.turretAngle=0;
  b.x=ARENA.w*0.82; b.y=ARENA.h*0.5; b.angle=Math.PI; b.turretAngle=Math.PI;
  for (const t of room.tanks) {
    t.hp=MAX_HP; t.shield=0; t.shieldTimer=0; t.fireCd=0; t.skillCd=0; t.alive=true; t.hitFlash=0;
  }
  room.bullets = [];
}

// ---------- 4. 权威模拟 ----------
function applyDamage(t, dmg) {
  if (t.shield > 0) { const ab = Math.min(t.shield, dmg); t.shield -= ab; dmg -= ab; }
  t.hp -= dmg; t.hitFlash = 0.12;
}
function onTankDestroyed(room, winnerSlot) {
  room.scores[winnerSlot] += 1; room.lastWinner = winnerSlot;
  room.state = 'roundEnd'; room.roundEndTimer = ROUND_END_DELAY;
}
function stepRoom(room, dt) {
  if (room.state === 'countdown') { room.countdown -= dt; if (room.countdown<=0) room.state='playing'; return; }
  if (room.state !== 'playing') return;
  const inputs = [room.players[0]?room.players[0].lastInput:EMPTY_INPUT,
                  room.players[1]?room.players[1].lastInput:EMPTY_INPUT];
  for (let i=0;i<2;i++) {
    const t = room.tanks[i], inp = inputs[i];
    if (!t.alive) continue;
    // 平移式移动（与 CyberTank 本体操作一致：W上 S下 A左 D右 即世界方向；鼠标控制炮口）
    const vx = (inp.right ? 1 : 0) - (inp.left ? 1 : 0);
    const vy = (inp.down ? 1 : 0) - (inp.up ? 1 : 0);
    const mlen = Math.hypot(vx, vy);
    if (mlen > 0) {
      t.x += (vx / mlen) * TANK_SPEED * dt;
      t.y += (vy / mlen) * TANK_SPEED * dt;
      t.angle = Math.atan2(vy, vx); // 车身朝移动方向
    }
    t.x = clamp(t.x, TANK_R, ARENA.w-TANK_R);   // 边界夹紧：防穿墙
    t.y = clamp(t.y, TANK_R, ARENA.h-TANK_R);
    t.turretAngle = inp.aim;
    t.fireCd = Math.max(0, t.fireCd-dt);
    t.skillCd = Math.max(0, t.skillCd-dt);
    if (t.shieldTimer>0) { t.shieldTimer-=dt; if (t.shieldTimer<=0) t.shield=0; }
    if (t.hitFlash>0) t.hitFlash = Math.max(0, t.hitFlash-dt);
    if (inp.fire && t.fireCd<=0) {                // 服务端限频开火
      const mx=t.x+Math.cos(t.turretAngle)*(TANK_R+6), my=t.y+Math.sin(t.turretAngle)*(TANK_R+6);
      room.bullets.push({ x:mx,y:my, vx:Math.cos(t.turretAngle)*BULLET_SPEED, vy:Math.sin(t.turretAngle)*BULLET_SPEED, owner:i });
      t.fireCd = FIRE_CD;
    }
    if (inp.skill && t.skillCd<=0) { t.shield=SHIELD_MAX; t.shieldTimer=SKILL_DUR; t.skillCd=SKILL_CD; }
  }
  const hitR = TANK_R + BULLET_R;
  for (let bi=room.bullets.length-1; bi>=0; bi--) {
    const b = room.bullets[bi];
    b.x += b.vx*dt; b.y += b.vy*dt;
    if (b.x<0||b.x>ARENA.w||b.y<0||b.y>ARENA.h) { room.bullets.splice(bi,1); continue; }
    const target = room.tanks[1-b.owner];
    if (target && target.alive && (b.x-target.x)**2+(b.y-target.y)**2 <= hitR*hitR) {
      applyDamage(target, DAMAGE); room.bullets.splice(bi,1);
      if (target.hp<=0) { target.alive=false; onTankDestroyed(room, 1-b.owner); }
    }
  }
}
function buildSnapshot(room) {
  return {
    phase: room.state, countdown: Math.max(0, Math.ceil(room.countdown)),
    scores: room.scores, lastWinner: room.lastWinner, arena: ARENA,
    tanks: room.tanks.map(t => ({ x:t.x,y:t.y,angle:t.angle,turretAngle:t.turretAngle,
      hp:t.hp, shield:t.shield, alive:t.alive, fireReady:t.fireCd<=0, skillCd:t.skillCd, hitFlash:t.hitFlash })),
    bullets: room.bullets.map(b => ({ x:b.x, y:b.y })),
  };
}
function broadcast(room, type, data) { io.to(room.id).emit(type, data); }

function tickAll() {
  for (const room of rooms.values()) {
    if (room.state==='playing'||room.state==='countdown') stepRoom(room, TICK_DT);
    else if (room.state==='roundEnd') {
      room.roundEndTimer -= TICK_DT;
      if (room.roundEndTimer<=0) {
        if (room.scores[0]>=ROUNDS_TO_WIN || room.scores[1]>=ROUNDS_TO_WIN) {
          room.state='finished'; broadcast(room,'matchEnd',{scores:room.scores});
        } else { placeTanks(room); room.state='countdown'; room.countdown=COUNTDOWN; }
      }
    }
    if (['countdown','playing','roundEnd'].includes(room.state)) broadcast(room,'snapshot',buildSnapshot(room));
    room.tick++;
  }
}
setInterval(tickAll, 1000/TICK_HZ);

// ---------- 5. 房间 / 队列 操作 ----------
function joinRoomAs(socket, room, slot) {
  socket.data.roomId = room.id; socket.join(room.id);
  room.players[slot] = { socketId: socket.id, slot, lastInput: sanitizeInput({}) };
  io.to(room.id).emit('peerJoined', { slot, count: room.players.filter(Boolean).length });
}
function maybeStart(room) {
  if (room.state==='waiting' && room.players.filter(Boolean).length===2) {
    placeTanks(room); room.state='countdown'; room.countdown=COUNTDOWN;
    broadcast(room,'matchStart',{ arena:ARENA, roundsToWin:ROUNDS_TO_WIN });
  }
}
function leaveQueue(socket) { const i=matchQueue.indexOf(socket.id); if (i>=0) matchQueue.splice(i,1); }
function leaveRoom(socket) {
  const rid = socket.data.roomId; if (!rid) return;
  const room = rooms.get(rid); socket.data.roomId=null; socket.leave(rid); if (!room) return;
  const p = room.players.find(p=>p&&p.socketId===socket.id);
  if (p) room.players[p.slot]=null;
  socket.to(rid).emit('peerLeft',{ slot:p?p.slot:-1 });
  if (room.players.filter(Boolean).length===0) rooms.delete(rid);
  else { room.state='finished'; broadcast(room,'opponentLeft',{}); }
}
function tryMatch() {
  while (matchQueue.length>=2) {
    const idA=matchQueue.shift(), idB=matchQueue.shift();
    const sa=io.sockets.sockets.get(idA), sb=io.sockets.sockets.get(idB);
    if (!sa||!sb) { if (sa) matchQueue.unshift(idA); if (sb) matchQueue.unshift(idB); break; }
    if (sa.data.roomId) leaveRoom(sa); if (sb.data.roomId) leaveRoom(sb);
    const room = createRoom(); joinRoomAs(sa,room,0); joinRoomAs(sb,room,1);
    sa.emit('roomCreated',{ roomId:room.id, slot:0, matched:true });
    sb.emit('roomJoined',{ roomId:room.id, slot:1, matched:true });
    maybeStart(room);
  }
}

// ---------- 6. Socket.IO 事件 ----------
io.on('connection', (socket) => {
  socket.data.roomId = null;
  socket.on('createRoom', () => {
    leaveQueue(socket); if (socket.data.roomId) leaveRoom(socket);
    const room = createRoom(); joinRoomAs(socket, room, 0);
    socket.emit('roomCreated', { roomId: room.id, slot: 0 });
  });
  socket.on('joinRoom', ({ roomId }) => {
    leaveQueue(socket);
    const rid = (roomId||'').toUpperCase().trim();
    const room = rooms.get(rid);
    if (!room) { socket.emit('errorMsg',{msg:'房间不存在，请确认房间号'}); return; }
    if (room.players.filter(Boolean).length>=2) { socket.emit('errorMsg',{msg:'房间已满'}); return; }
    const slot = room.players[0] ? 1 : 0;
    joinRoomAs(socket, room, slot);
    socket.emit('roomJoined', { roomId: room.id, slot });
    maybeStart(room);
  });
  socket.on('quickMatch', () => {
    if (socket.data.roomId) { socket.emit('errorMsg',{msg:'你已在对局中'}); return; }
    if (!matchQueue.includes(socket.id)) { matchQueue.push(socket.id); socket.emit('queued',{position:matchQueue.length}); tryMatch(); }
  });
  socket.on('input', (inp) => {
    const room = rooms.get(socket.data.roomId);
    if (!room || room.state!=='playing') return;            // 非对局状态直接丢弃
    const p = room.players.find(p=>p&&p.socketId===socket.id);
    if (!p) return;
    room.players[p.slot].lastInput = sanitizeInput(inp);     // 服务端清洗后再用
  });
  socket.on('leave', () => { leaveQueue(socket); leaveRoom(socket); });
  socket.on('disconnect', () => { leaveQueue(socket); leaveRoom(socket); });
});

server.listen(PORT, () => {
  console.log(`[CyberTank 联机] 服务已启动: http://localhost:${PORT}`);
  console.log(`[CyberTank 联机] 局域网其它设备访问: http://<本机IP>:${PORT}`);
});
```

      const left=!!(keys['KeyA']||keys['ArrowLeft']), right=!!(keys['KeyD']||keys['ArrowRight']);
      const fire=mouse.down||!!keys['Space'];
      const skill=mouse.skill||!!keys['ShiftLeft']||!!keys['ShiftRight'];
      let aim = mySlot===0?0:Math.PI;
      if (lastSnap && lastSnap.tanks[mySlot]) { const me=lastSnap.tanks[mySlot]; aim=Math.atan2(mouse.y-me.y, mouse.x-me.x); }
      return { up, down, left, right, fire, skill, aim };
    }
    // 按 30Hz 上报输入
    setInterval(() => { if (mySlot!==null && socket.connected) socket.emit('input', gatherInput()); }, 1000/30);

    // —— 渲染循环（只画服务端快照）——
    const ctx = canvas.getContext('2d');
    function drawTank(t, isMe) {
      if (!t.alive) return;
      ctx.save(); ctx.translate(t.x, t.y);
      ctx.save(); ctx.rotate(t.angle); ctx.fillStyle=isMe?'#2b6cff':'#ff3b6b'; ctx.strokeStyle='#0c0f1a'; ctx.lineWidth=2;
      ctx.beginPath(); ctx.roundRect(-TANK_R,-TANK_R*0.75,TANK_R*2,TANK_R*1.5,5); ctx.fill(); ctx.stroke(); ctx.restore();
      ctx.save(); ctx.rotate(t.turretAngle); ctx.fillStyle='#cfe0ff'; ctx.fillRect(0,-3,TANK_R+10,6);
      ctx.beginPath(); ctx.arc(0,0,6,0,Math.PI*2); ctx.fill(); ctx.restore();
      if (t.shield>0) { ctx.strokeStyle='rgba(90,200,255,.8)'; ctx.lineWidth=3; ctx.beginPath(); ctx.arc(0,0,TANK_R+6,0,Math.PI*2); ctx.stroke(); }
      if (t.hitFlash>0) { ctx.fillStyle='rgba(255,255,255,.5)'; ctx.beginPath(); ctx.arc(0,0,TANK_R,0,Math.PI*2); ctx.fill(); }
      ctx.restore();
      const bw=44,bh=5; ctx.fillStyle='#000'; ctx.fillRect(t.x-bw/2,t.y-TANK_R-14,bw,bh);
      ctx.fillStyle=isMe?'#2b6cff':'#ff3b6b'; ctx.fillRect(t.x-bw/2,t.y-TANK_R-14,bw*Math.max(0,t.hp)/100,bh);
    }
    function render() {
      requestAnimationFrame(render);
      ctx.clearRect(0,0,canvas.width,canvas.height);
      if (!lastSnap) return;
      const A = lastSnap.arena;
      ctx.strokeStyle='#1b2233'; ctx.lineWidth=1;
      for (let x=0;x<=A.w;x+=40){ ctx.beginPath(); ctx.moveTo(x,0); ctx.lineTo(x,A.h); ctx.stroke(); }
      for (let y=0;y<=A.h;y+=40){ ctx.beginPath(); ctx.moveTo(0,y); ctx.lineTo(A.w,y); ctx.stroke(); }
      ctx.fillStyle='#ffd54a'; for (const b of lastSnap.bullets){ ctx.beginPath(); ctx.arc(b.x,b.y,5,0,Math.PI*2); ctx.fill(); }
      drawTank(lastSnap.tanks[0], mySlot===0); drawTank(lastSnap.tanks[1], mySlot===1);
      ctx.fillStyle='#e7ecf3'; ctx.font='bold 20px system-ui'; ctx.textAlign='center';
      ctx.fillText('P1  '+lastSnap.scores[0]+'  :  '+lastSnap.scores[1]+'  P2', A.w/2, 28);
      ctx.fillStyle='#ffd54a';
      if (lastSnap.phase==='countdown'){ ctx.font='bold 64px system-ui'; ctx.fillText(lastSnap.countdown,A.w/2,A.h/2); }
      else if (lastSnap.phase==='roundEnd'){ ctx.font='bold 36px system-ui';
        ctx.fillText(lastSnap.lastWinner===mySlot?'你赢下本回合！':'对手赢下本回合', A.w/2, A.h/2); }
      ctx.textAlign='left';
    }
    render();
  })();
  </script>
</body>

### 如何并入你原有的 CyberTank（而非只用示例页）

1. 把 `online/` 作为独立服务运行（它只负责联机，不碰你原游戏文件）。
2. 在你的 `menu.js` 里加三个按钮，点击时 `socket.emit('createRoom' | 'joinRoom' | 'quickMatch')`，逻辑与示例页完全一致。
3. 新增一个 `CT_MODE_ONLINE`：开局后**不再本地跑物理**，而是：
   - 输入：把你原有的 `CT_INPUT` 读出来，按上面 `gatherInput()` 的格式发给服务端；
   - 渲染：每收到 `snapshot`，用快照里的 `x/y/angle/turretAngle/hp/shield` 去更新两个「木偶」`Tank` 实例并调用你现有的 `Tank.draw()`。
4. 这样你原有的美术、技能特效、音效全部复用，只替换「谁来决定位置/命中」这一层。

## 6. 公网部署注意事项 & 常见问题排查

### 6.1 公网部署

- **最简方案**：把 `online/` 部署到任意支持 Node 的云主机（如轻量应用服务器、Railway、Render、Fly.io）。
  - `npm install` → `npm start`，确保 `PORT` 环境变量被平台读取（已用 `process.env.PORT || 3000`）。
- **跨域收紧**：公网时把 `new Server(server, { cors: { origin: '*' } })` 的 `origin` 改为你的前端域名（如 `'https://game.example.com'`），避免被任意站点的脚本连入。
- **前端连公网地址**：把示例页里的 `const socket = io();` 改成 `const socket = io('https://你的域名');`；并入原游戏同理。
- **用 Nginx 反代 + SSL（wss）**（推荐，便于共用 443/80、自动上 HTTPS）：
  - 以下样例假定前端页面也由本机 Nginx 托管（根路径），联机服务跑在 `127.0.0.1:3000`。
  - 证书用 Let's Encrypt（`certbot` 生成）；`/socket.io/` 这段是 WebSocket 升级的关键，**不能漏 `Upgrade`/`Connection`**。
  ```nginx
  server {
    listen 443 ssl http2;
    server_name game.example.com;            # 改成你的域名

    ssl_certificate     /etc/letsencrypt/live/game.example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/game.example.com/privkey.pem;
    # 建议的最低安全配置
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;

    # 前端静态页面（可选：若把 online/public 直接交给 Nginx 托管）
    root /var/www/cybertank/online/public;
    index index.html;
    location / { try_files $uri $uri/ /index.html; }

    # 联机 WebSocket 反代（wss 即通过 443 的加密 WebSocket）
    location /socket.io/ {
      proxy_pass http://127.0.0.1:3000;
      proxy_http_version 1.1;
      proxy_set_header Upgrade $http_upgrade;          # WebSocket 升级必须
      proxy_set_header Connection "upgrade";           # 关键：告诉后端这是长连接
      proxy_set_header Host $host;
      proxy_set_header X-Real-IP $remote_addr;
      proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
      proxy_set_header X-Forwarded-Proto $scheme;
      proxy_read_timeout 3600s;                        # 长连接保活，避免被 Nginx 提前掐断
      proxy_send_timeout 3600s;
    }
  }

  # 80 端口统一 301 跳转到 HTTPS
  server {
    listen 80;
    server_name game.example.com;
    return 301 https://$host$request_uri;
  }
  ```
  - 前端连接地址改为 `const socket = io('https://game.example.com');`（wss 自动走 443；`io()` 不写协议时浏览器会用页面同协议，页面已是 https 则自动 wss）。
  - 若 Nginx 与联机服务**不在同一台机**，把 `proxy_pass http://127.0.0.1:3000;` 换成内网/公网可达地址，并确保该链路本身可信（建议走内网或加一层 mTLS，不要裸奔到公网）。

### 6.2 排查：联机不同步

| 现象 | 可能原因 | 解决 |
|------|----------|------|
| 两端画面完全各玩各的 | 客户端在本地跑了物理，没用服务端快照 | 确认渲染只读 `snapshot`，输入只发不本地算 |
| 坦克轻微抖动/瞬移 | 客户端做了预测但没接校正 | 新手先**关掉预测**，只用快照渲染；要跟手再加重校正 |
| 一人开火另一方看不到子弹 | 子弹只存在客户端 | 子弹必须在服务端生成并随快照下发 |
| 偶发位置偏差越来越大 | 两端模拟步长/随机不一致 | 所有随机与物理只在服务端算，客户端零随机 |

### 6.3 排查：跨域（CORS）报错

- 现象：控制台 `Access to XMLHttpRequest ... has been blocked by CORS`。
- 开发期：保持 `cors:{ origin:'*' }`。
- 公网：把 `origin` 设为前端真实域名；前端 `io('https://域名')` 与之对应。
- 仍不行：确认前端页面确实由该域名提供，而非 `file://` 直接打开（本地文件协议也会被拦）。

### 6.4 排查：局域网访问失败

- 确认服务端在「主机」上 `npm start` 成功，且防火墙放行 `3000` 端口（Windows 防火墙 / 云安全组都要放）。
- 其它设备用 `http://<主机局域网IP>:3000` 访问（主机 IP 用 `ipconfig` 查，形如 `192.168.x.x`）。
- 若用 `localhost` 能开、IP 打不开：基本是防火墙/端口未放行。
- 路由器层面：纯局域网无需端口映射；只有从**外网**访问才需要路由器端口转发（公网建议直接用云主机，别在自家宽带做映射）。

### 6.5 进阶（可选）

- **手感优化**：对「自己的坦克」做输入预测（本地先动，收到快照再校正），其余仍按快照渲染。
- **防作弊加强**：服务端校验「单 tick 移动距离 ≤ 速度×dt」、限制开火频率（已实现）、校验技能冷却（已实现）。
- **断线重连**：在 `peerLeft` 后给个 10 秒窗口，原 socket 重连可 `joinRoom` 回原房（需服务端按用户标识而非 socket.id 记忆房间）。
